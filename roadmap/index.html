Phase 0 — 1–2 weeks
Stops-the-line
Dedup ×3 types, seal-at-drain + pre-wrap rekey, handshake allowlist. CI builds vpn + hardware-tpm.
Gate: loopback + 370 tests green, no doc drift.
Phase 1 — 3–5 weeks
Reachable mesh
Full ICE/STUN/TURN + DERP relay, QUIC/multipath + BBR, real CGR over TLE contacts.
Landed: RFC 8489 STUN + RFC 8445 ICE replace the port-guessing loop; TURN allocation, DERP blind relay and the direct → relay → TURN ladder are wired; UPnP-IGD/NAT-PMP give an opportunistic candidate; CGR is consulted, not just populated; CUBIC/NewReno/BBR + TransitGovernor shape the tunnel from measured path capacity; QUIC is an optional GTF carrier (--features quic, GHOST_QUIC=1). Open: multipath-QUIC, and no real gateway/TURN server/middlebox has been exercised.
Gate: 2 NAT44 + LTE phone, no port-forward, iperf survives handover. Not yet run: every traversal test is loopback or in-process.
Phase 2 — 3–4 weeks
Future-proof crypto
ML-DSA identity, double-ratchet + XChaCha20, real HSM via tss-esapi/cryptoki, Tamarin model.
Gate: PQ sig migration + forward-secrecy proof, no mock primitives in scope.
Phase 3 — 2–3 weeks
Real anonymity
Constant 576 B frames + cover traffic, 3-hop Sphinx onion, disjoint shard enforcement.
Gate: DPI classifier = random, single-relay compromise leaks 0 bytes.
Phase 4 — 2–3 weeks
Shippable product
Signed wintun 0.14.x, macOS NE + Linux deb, Android WiFi→LTE path migration, DNS/IPv6 hygiene.
Gate: per-user install, store signatures, handover mid-SSH no drop.

1.

Fair-share transit enforcement

✓ Implemented in Core (L0–L9)

Reciprocity engine (TitForTatEnforcer) tracking contributed transit bandwidth versus consumption, evicting leecher peers and prioritizing nodes that actively relay traffic.

2.

Automated UDP hole punching & Multi-Hop Routing

✓ Implemented in Core (L0–L9)

NAT hole puncher with keepalive heartbeat mapping combined with Level 2 multi-hop routing, hop decrements, and dynamic carrier relay chains.

3.

Egress IP rotation & SOCKS5 Proxy

✓ Implemented in Core (L0–L9)

Dynamic exit IP pool rotation (ExitIpRotator) paired with an integrated local SOCKS5 proxy (127.0.0.1:1080) for anonymous client egress onto public WAN.

4.

Zero-knowledge peer discovery & Signed Beacons

✓ Implemented in Core (L0–L9)

ZK proof vouchers (ZkAuthenticator), Ed25519-signed multicast beacons on 239.255.0.1:2270, DNS seed resolution, and cold-boot peers.cache persistence.

5.

Post-Quantum KEM & Strict GTF Wire Frames

✓ Implemented in Core (L0–L9)

NIST FIPS 203 ML-KEM-512 (Kyber) + X25519 hybrid key agreement with live session hash tracking, strict 512-byte Ghost Transport Frames (GTF), and L5 jitter noise padding.

6.

Long-stream forward error correction

✓ Implemented in Core (L0–L9)

1024-bit IRA LDPC codec (LdpcCodec) working alongside Reed-Solomon RS(2,1) erasure coding for secondary forward error correction on unstable lossy links.

7.

Encrypted runtime memory

✓ Implemented in Core (L0–L9)

AES-256-XTS memory defense (LockedMemory) with OS page pinning (mlock / VirtualLock) and compiler-barrier zeroization on drop to prevent cold-boot memory scraping.

8.

Hardware security key storage & TPM Enclave

✓ Implemented in Core (L0–L9)

Hardware TPM 2.0 enclave binding (SoftwareTpm / HardwareTpm) with tamper response and Network Time Security (NTS) multi-source voting.

9.

Kernel-bypass packet acceleration

✓ Implemented in Core (L0–L9)

Zero-copy lockless packet dispatcher (LocklessDispatcher) and AF_XDP ring-buffer kernel bypass for multi-gigabit throughput.

10.

Satellite & orbital mesh tracking

Predictive orbit trajectory modeling (SGP4/TLE parser), Doppler shift simulation, and orbital line-of-sight transit calculations.
