Direct device-to-device networking • No accounts • No servers

Connect your computers directly. No companies. No logins. No surveillance.

Global Ghost Net links your home server, laptop, and cloud machines into one private network that works from anywhere. There is no account to create, no subscription, and no middleman such as Tailscale or Cloudflare sitting in the path — your devices talk to each other, encrypted end to end.

Private Network YOUR DEVICES ONLY

A closed network for your own machines, protected by your private key. Only devices you approve can join — everyone else is ignored.

Public Swarm OPEN MESH

An open mesh where devices help bounce encrypted traffic for each other. More participants make it harder to block — a practical way around censorship.

How it protects you

Strong protection, explained plainly

Here is what is actually happening to keep you safe — no jargon.

01 / SPLIT ACROSS ROUTES

Multi-Path Traffic Splitting

Think of tearing a secret letter into three pieces and sending each with a different courier. Anyone who intercepts one piece learns nothing useful, and if one courier never arrives, the other two still deliver the full message intact.

02 / NOTHING TO HACK

Zero Central Servers

There is no company database to get hacked, no account to sign up for, and no single machine whose failure takes the whole network down. Your devices find each other on their own.

03 / BUILT TO LAST

Future-Proof Encryption

Everything is scrambled with next-generation security designed to resist even quantum computers — including data someone copies today hoping to crack it years from now.

04 / MEMORY ONLY

Runs Purely in Memory

Your encryption keys exist only in RAM while a session is running. They are never written to your hard drive or SSD, so a stolen laptop disk cannot leak them.

There is nothing to log, either: the software has no telemetry, no analytics, and no usage tracking of any kind.

Quickstart

Up and running in a few minutes

One program, no account, no installer wizard. Run it and you are on the network.

01 Download and run the program

Global Ghost Net is a single self-contained program with no extra dependencies. Build it from source with Rust, or grab a ready-to-run release.

# Build and install from source (requires Rust)
cargo install --git https://github.com/KELLERBABG/Global-Ghost-Net.git

# Or clone and compile a release build
git clone https://github.com/KELLERBABG/Global-Ghost-Net.git
cd Global-Ghost-Net && cargo build --release

# Start it
vantablack

02 Optional: make the network private

By default you join the open Public Swarm. To keep the network exclusive to your own devices, generate a private key and start the program with it. Devices without the key are dropped before they can connect.

# Generate a private key (keep it secret)
openssl rand -hex 32

# Start your private network
export GHOST_PSK=<paste-your-key>
vantablack

Use the same key on every device you want in your network.

03 Send your traffic through it — or try the full demo

Point your browser or apps at the built-in local proxy. Or, if you want to watch the whole thing work under simulated real-world network conditions, start the Docker demo.

# Route a request through the encrypted network
curl --socks5 127.0.0.1:1080 https://checkip.amazonaws.com

# Or run the multi-hop network demo with a live dashboard
docker compose -f docker-compose.wan.yml up -d
open http://localhost:8080
